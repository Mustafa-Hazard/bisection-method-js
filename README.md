# Bisection Method Calculator

A simple web-based calculator that finds roots of both transcendental and non-transcendental equations using the **Bisection Method**.

## 🚀 Features
- Supports transcendental and non-transcendental equations
- Step-by-step root approximation
- Easy-to-use web interface
- Built with HTML, CSS, and JavaScript

## 🧮 How It Works
The Bisection Method is a numerical technique used to find roots of equations by repeatedly narrowing down an interval where the sign of the function changes.

## 🖥️ Usage
1. Enter the equation in the input box.  
2. Set the interval `[a, b]` and desired error tolerance.  
3. Click **Calculate** to view the root and iterations.
